# LEVEL 1
1. 현재, 데스크톱, 모바일 기준 모두 화면이 조금씩 깨짐. 두드러지는 부분은 특히 input태그쪽임. 옆 input태그와 겹쳐보이는 부분이 존재함. 이를 수정하고 싶음.
2. 차량 상제 정보 컴포넌트에 대한 수정사항이 있음. 목록의 옆에 나오는게 아닌, 간단하게 모달창으로 띄워졌으면 좋겠음. 이는 목록의 수정, 삭제 버튼을 제외한 이름부터 연식까지의 부분을 클릭할 때 이벤트 발생하게 하고 싶음.
3. 목록이 페이징처리가 되었으면 좋겠음. 목록의 우측 상단 또는 좌측 상단에 페이징 처리를 몇 개로 할지에 대한 선택을 사용자가 선택할 수 있게, select, option으로 제공하고 싶음. (10개, 30개, 50개)
4. 수정, 삭제 버튼의 텍스트가 wrapping 처리가 어색함. 밀려나서 위 아래로 적혀있음.
5. 모바일 환경에서의 UI가 전체적으로 좌우 스크롤이 필요한 것으로 보임. 모바일 디바이스에 맞게 수정하고 싶음.
6. 차량 정보 등록 및 수정도 모달창으로 처리해서 목록이 깔끔하게 보이게 하고 싶음. 수정 버튼을 누르면 현재 수정에 관련된 컴포넌트가 모달로 나오게끔 하고 싶고, 삭제 버튼은 '정말 삭제하시겠습니까?' 하는 확인 모달창이 나왔으면 좋겠음. 등록 버튼은 상단 Navbar쪽에 위치했으면 좋겠음

# LEVEL 2
1. 현재, 연식과 가격 input에서 문제가 음수가 입력되는 문제를 발견함. 이는 해당 input태그에 min 속성을 넣었음에도 유효하게 입력되는 것임. 정규표현식과 onChange 이벤트핸들러를 이용해서 아예 입력되지 않게 했으면 좋겠음. 이는 검색쪽 input과 등록쪽 input 모두 해당되는 이야기임.
2. 상단 Navbar에서 로고 부분을 클릭하면 초기화된 것과 같은 효과를 냈으면 좋겠음..

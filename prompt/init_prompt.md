당신은 20년 이상의 경력을 가진 풀 스택 개발자입니다.
다음의 요구를 읽고 프로젝트를 생성하세요.

[ 기술 스택 ]
1. Vite + React
2. Tailwindcss
3. expressjs
4. DB는 별도로 사용하지 않고 서버의 메모리를 이용함.

[ 배포 ]
1. Render
2. 프론트엔드는 빌드해서 static으로 Render에 서버 올릴 때 같이 배포

[ 필요 사항 ]
1. server.js에 있는 더미데이터 형식을 이용하여, 더미데이터를 대략 50-100개 정도로 만들것. 이는 따로 프로젝트 루트/data/data.json이라고 만들것.
2. UI의 아이콘은 Material 3를 따를 것. 전체적으로 너무 둥글둥글하지 않는 정도의 컨테이너 혹은 박스, 버튼 등을 사용할 것. tailwindcss 기준 rounded-none 혹은 sm 정도 사용할 것.
3. UI는 모바일 환경을 고려해서 반응형으로 만들 것.
4. CRUD를 중점적으로 보는 프로젝트임을 잊지 말 것.

[ 프로젝트 소개 ]
중고차 정보를 등록, 조회, 수정, 삭제할 수 있는 웹 서비스입니다.
관리자는 차량 정보를 등록하고, 사용자는 조건에 맞는 차량을 검색할 수 있습니다.
우선 프로토타입으로서 관리자가 로그인되어있다는 전제하에 만듭니다.

[ 주요 기능 ]
- 차량 목록 조회
- 차량 상세 조회
- 차량 등록
- 차량 수정
- 차량 삭제
- 제조사별 검색

[ 요구사항 정의서 ]
| 번호 | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F-01 | 차량 목록 조회 | 등록된 차량 목록을 조회한다. | 상 |
| F-02 | 차량 등록 | 차량명, 가격, 제조사, 연식을 입력해 차량을 등록한다. | 상 |
| F-03 | 차량 수정 | 등록된 차량 정보를 수정한다. | 중 |
| F-04 | 차량 삭제 | 선택한 차량 정보를 삭제한다. | 중 |
| F-05 | 차량 검색 | 제조사 또는 가격 조건으로 차량을 검색한다. | 중 |

[ 화면 설계서 ]
1. 차량 목록 화면
 - 화면 목적: 등록된 차량 목록을 보여준다.
 - 주요 기능: 목록 조회, 검색, 상세 보기 이동
 - 버튼: 검색, 등록, 수정, 삭제
 - 호출 API: GET /api/cars 등

2. 차량 상세 보기
 - 화면 목적: 차량 목록에서 선택된 차량의 상세 정보를 보여준다.
 - 주요 기능: ID값으로 해당 차량 정보 조회
 - 버튼: 뒤로가기, 상세 정보 수정
 - 호출 API: GET /api/cars/:id

화면 이미지는 assets/screenshots/ 에 저장한다.

[ 트러블슈팅 기록 작성 ]
/prompt에 troubleShooting.md로 저장한다.
양식은 다음과 같다.
```markdown
#### 문제
React에서 Express API를 호출할 때 CORS 오류가 발생한다.

#### 원인
프론트엔드와 백엔드의 포트가 달라 브라우저에서 요청을 차단했다.

#### 해결
Express 서버에 cors 미드웨어를 추가했다.

const cors = require("cors");
app.use(cors());

---

```
위 양식의 아래쪽 소스 부분은 md의 코드 양식으로 적을 것.
